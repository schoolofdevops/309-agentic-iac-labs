# Agentic Infrastructure as Code — Labs

Public learner lab repository for the School of DevOps & AI course **Agentic Infrastructure as Code**.

The project grows from a governed Terraform repair into a Production AI Workload Platform. The core learner path must remain runnable on an 8 GB laptop, without a GPU, paid cloud account, or model API key.

## Current status

Phase 0 viability validation is in progress. Learner labs, module checkpoints, and tags will be published only after their associated resource profile has direct validation evidence.

## Planned learner checkpoints

Module tags will follow the pattern `m01-start` / `m01-complete` through `m13-start` / `m13-complete`.

## Safety boundary

Agents may inspect, propose, change, and verify within each documented lab task. Human approval remains required for destructive or deployment actions.
